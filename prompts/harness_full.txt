weights.bin holds the trained weights of a neural network that generates images of galaxies. It is a transformer with 6 layers and 8 attention heads per layer. It reads a galaxy image as a sequence of 256 patches, starting at the centre of the image and spiralling outward, and at every position it predicts the next patch. This is exactly how it computes (numpy):

```python
import numpy as np

# weights.bin is 14,553,984 float32 numbers (little-endian) and nothing else: the tensors below, one after
# another in this order, each stored row-major. Matrices are (out, in) and are applied as x @ M.T.
SHAPES = [("enc_fc", (1536, 768)), ("enc_proj", (384, 1536)), ("pos_emb", (1024, 384))]
for l in range(6):
    SHAPES += [(f"ln1.{l}", (384,)), (f"W_qkv.{l}", (1152, 384)), (f"W_o.{l}", (384, 384)),
               (f"ln2.{l}", (384,)), (f"W_fc.{l}", (1536, 384)), (f"W_proj.{l}", (384, 1536))]
SHAPES += [("lnf", (384,)), ("dec_fc", (1536, 384)), ("dec_proj", (768, 1536))]


def load_weights(path="weights.bin"):
    flat, W, i = np.fromfile(path, dtype="<f4"), {}, 0
    for name, shape in SHAPES:
        n = int(np.prod(shape))
        W[name] = flat[i:i + n].reshape(shape)
        i += n
    assert i == flat.size
    return W

def image_to_sequence(img):
    """img: (256, 256, 3) RGB image, row 0 at the top. Returns the (256, 768) input sequence."""
    seq = np.zeros((256, 768))
    for k, (r, c) in enumerate(ORDER):
        p = img[16 * r:16 * r + 16, 16 * c:16 * c + 16].astype(np.float64)  # (16 rows, 16 columns, 3 colours)
        v = p.transpose(1, 0, 2).reshape(768)    # entry (x * 16 + y) * 3 + colour, x = column and y = row in the patch
        seq[k] = (v - v.mean()) / (v.std(ddof=1) + 1e-8)                    # each patch normalised on its own
    return seq


def sequence_to_image(seq):
    """(n, 768) sequence -> (256, 256, 3) image; each patch keeps its own normalisation, patches beyond n stay 0."""
    img = np.zeros((256, 256, 3))
    for k, (r, c) in enumerate(ORDER[:len(seq)]):
        img[16 * r:16 * r + 16, 16 * c:16 * c + 16] = np.asarray(seq[k]).reshape(16, 16, 3).transpose(1, 0, 2)
    return img


def gelu(x):                                          # tanh approximation
    return 0.5 * x * (1 + np.tanh(np.sqrt(2 / np.pi) * (x + 0.044715 * x ** 3)))


def layer_norm(x, w):                                 # over the last axis, eps 1e-5, no bias
    mu = x.mean(-1, keepdims=True)
    var = ((x - mu) ** 2).mean(-1, keepdims=True)
    return (x - mu) / np.sqrt(var + 1e-5) * w


def predict(seq, W):
    """seq: (n, 768) normalised patches in sequence order, 1 <= n <= 256.
    Returns (n, 768): row t is the network's prediction of patch t + 1."""
    n, d, H = len(seq), 384, 8
    hd = d // H
    x = gelu(seq @ W["enc_fc"].T) @ W["enc_proj"].T + W["pos_emb"][:n]   # position k adds row k of pos_emb
    for l in range(6):
        h = layer_norm(x, W[f"ln1.{l}"])
        q, k, v = np.split(h @ W[f"W_qkv.{l}"].T, 3, axis=-1)           # rows 0-383 of W_qkv give q, 384-767 k, 768-1151 v
        out = np.zeros((n, d))
        for j in range(H):                                                # head j uses dimensions 48j .. 48j+47
            s = slice(j * hd, (j + 1) * hd)
            att = q[:, s] @ k[:, s].T / np.sqrt(hd)                       # (n, n)
            att = att + np.triu(np.full((n, n), -np.inf), 1)              # causal: position i sees positions 0..i
            att = np.exp(att - att.max(-1, keepdims=True))
            att = att / att.sum(-1, keepdims=True)
            out[:, s] = att @ v[:, s]
        x = x + out @ W[f"W_o.{l}"].T
        h = layer_norm(x, W[f"ln2.{l}"])
        x = x + gelu(h @ W[f"W_fc.{l}"].T) @ W[f"W_proj.{l}"].T
    h = layer_norm(x, W["lnf"])
    return gelu(h @ W["dec_fc"].T) @ W["dec_proj"].T
```

The data: colour (RGB) JPEG images of galaxies from the DESI Legacy Imaging Surveys, 256 x 256 pixels, each centred on a galaxy. ORDER starts at (7, 8), just above and to the right of the image centre, and goes clockwise round the centre one square ring at a time: ring r (r = 1..8) is the border of the central 2r x 2r block of patches and takes positions (2r-2)^2 to (2r)^2 - 1 (ring 1 is positions 0-3, ring 2 is 4-15, ..., ring 8, the edge of the image, is 196-255). Each ring starts in its top row and ends at its top-left corner; the last patch, ORDER[255], is the top-left corner of the image. Each patch is normalised on its own (mean 0, standard deviation 1 over its 768 numbers), so the network never sees how bright a patch is, only its pattern. Every image is 256 patches long, so only rows 0-255 of pos_emb are ever used.

Training: from random initialization (every matrix entry drawn from a normal distribution with standard deviation 0.02, or 0.005774 for enc_proj, W_o, W_proj and dec_proj; LayerNorm weights 1), next-patch prediction: for t = 0..254, output row t is compared with patch t + 1 of the real image by the Huber loss (delta 1, averaged over all numbers). AdamW (betas 0.9 and 0.95, weight decay 0.1 on all matrices including pos_emb and none on the LayerNorm weights, gradient clipping at 1.0), learning rate warmed up to 0.001 over 2,000 steps and then cosine-decayed towards 0.0001; 29,000 steps of 640 images each, in bfloat16 mixed precision.

Measured on 32 held-out galaxy images (sequences from image_to_sequence): the mean Huber loss of predict(seq, W)[:-1] against seq[1:] is 0.19. For comparison, predicting all zeros gives 0.43, and predicting that each patch repeats the one before it gives 0.58.
